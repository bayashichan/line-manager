# 面談の日程調整 と リマインダー配信

「個別」とひとこと送ってもらうだけで、日程の候補を自動で返し、番号（またはボタンのタップ）で確定。
確定したら、事前質問・録音のお願い・前日の連絡などを決まったタイミングで自動送信します。

```
友だち「個別」
  └→ 自動返信: 候補日（番号付き）＋ タップで選べるボタン        ← 送信枠を消費しない（応答API）
        ├ 「1」やボタン → 確定の返信・タグ付け・リマインダー登録   ← 送信枠を消費しない
        ├ 「別の日程を希望」→ 受付の返信（その後はあなたが LINE で対応）
        ├ 「今回は見送る」→ お礼の返信
        └ 24時間返事なし → 1回だけ催促（候補とボタン付き）       ← 1通消費
確定した人
  └→ リマインダー: 3日前 事前質問 / 2日前 録音のお願い / 前日 連絡 / 1時間前 など ← 1通ずつ消費
```

## 最初にやること

1. **Supabase で SQL を実行**
   [`supabase/migrations/20261001000000_add_booking_and_reminders.sql`](../supabase/migrations/20261001000000_add_booking_and_reminders.sql)
2. **定期処理を5分ごとに動かす**（まだなら）
   Upstash の QStash で `/api/cron/tick` を5分ごとに呼ぶ（手順は [docs/mcp-setup.md](mcp-setup.md) の「4.」）。
   これがないと、催促とリマインダーが1日1回（朝9時）しか送られません。
3. **LINE 公式アカウントの管理画面で「個別」の応答メッセージを設定していれば、オフにする**
   両方が返信すると二重になります。

## 使い方

### 1. リマインダーを作る（管理画面 → リマインダー）

「新規作成」から、面談までに送るメッセージを並べます。例:

| タイミング | 内容 |
|---|---|
| 3日前 20:00 | `{name}さん、{日時}の面談の前に、次の質問にお答えください。…` |
| 2日前 20:00 | 面談で使う音声の録音のお願い |
| 前日 20:00 | `明日 {時刻} からお待ちしています。` |
| 1時間前 | Meet の URL など |
| 翌日 10:00 | 面談のお礼・感想のお願い（予定のあとも設定できます） |

- 差し込み: `{name}` 名前 / `{日時}` 10月3日(土) 10:00 / `{日付}` / `{時刻}` / `{予定}` 予定の名前 /
  `{会議URL}` Google Meet の URL（Googleカレンダー連携を使うとき。ないときは空）
- 「登録した時点で送信時刻を過ぎているメッセージは、予定の前ならすぐ送る」をオンにしておくと、
  2日後の面談が決まったときも「3日前の事前質問」がすぐ届きます（予定を過ぎたものは送りません）。

### 2. 日程調整を設定する（管理画面 → 面談の日程調整）

- 「自動の日程調整を使う」をオン
- きっかけのキーワード: `個別`（完全一致。「個別！」なども反応。「個別相談の料金は？」には反応しない）
- 確定した人に付けるタグ・登録するリマインダーを選ぶ
- 文面はすべて変えられます。右側のプレビューで見え方を確認できます
- 「保存」

### 3. 空き枠を登録する

「面談の空き枠」で日付と開始時刻（例: `10:00 13:00 16:00`）を入れて「追加」。
候補には、早い順に「案内する候補の数」だけ出します（「何時間後以降」より先の枠だけ）。

- 予定が入ったら「締め切る」、戻すときは「再開」
- 予約の取り消しは枠の「取り消す」。枠が空きに戻り、その人のリマインダーも止まります
  （相手への連絡は自動では送りません）

### 4. 「要対応」を確認する

「日程のやりとり」で次の人に **要対応** が付きます。LINE でご本人に返信してください。

- 別日程を希望した人
- 案内できる空き枠がなかった人
- 番号以外の返事（質問など）をくれた人（この人には催促しません）

## Googleカレンダー連携（任意）

**申込者の手順は変わりません**（「個別」→ LINE で番号を選ぶだけ。Google のログインや予約ページは不要）。
カレンダーはあなたの側だけで使います。

| 連携すると | 内容 |
|---|---|
| 空き枠を自動で作る | 受付する曜日・時間帯の中で、カレンダーに予定がない時間を空き枠にする（5分ごと） |
| 予定が入った枠は自動で締め切る | 予定がなくなれば自動で再開。終日の予定（出張・休みなど）がある日は枠を作らない |
| 確定の直前にもう一度確認 | 同期の合間に予定が入っていたら、お詫びして残りの候補を出し直す |
| 確定したら予定を作る | あなたのカレンダーに「初回無料面談：名前」の予定と Google Meet の URL を作る |
| 取り消したら予定も消す | 管理画面で予約を取り消すと、カレンダーの予定も削除 |

連携しなくても、これまでどおり手動の空き枠で使えます。連携後も手動の枠は残り、併用できます。

### 準備（最初の1回だけ・約15分）

**A. Google Cloud で「このツールがカレンダーを使う許可」の設定を作る**

1. [Google Cloud コンソール](https://console.cloud.google.com/) を開き、上部の「プロジェクトを選択」→「新しいプロジェクト」
   （名前は `line-manager` など何でも可）→「作成」
2. 上部の検索欄で **Google Calendar API** を検索 →「有効にする」
3. 左メニュー「APIとサービス」→「OAuth 同意画面」（「Google Auth Platform」と表示される場合も同じ）→「開始」
   - アプリ名: `LINE Manager` など / サポートメール: ご自分のアドレス
   - 対象: **外部**（Gmail のアカウントはこちら。Google Workspace をお使いで、同じ組織のアカウントだけで使うなら「内部」）
   - 連絡先メール: ご自分のアドレス →「作成」
4. 「ブランディング」で次の3つを入れて「保存」（未入力だと「アプリを公開」が押せません）
   - アプリケーションのホームページ: `https://（このツールのドメイン）`
   - アプリケーション プライバシー ポリシー リンク: `https://（このツールのドメイン）/privacy`（このツールに用意済み）
   - 承認済みドメイン:「ドメインを追加」→ `（このツールのドメイン）`（例: `line-manager-omega.vercel.app`。`https://` は付けない）
   - ロゴは**アップロードしない**（アップロードすると Google の審査が必要になります）。利用規約リンクは空欄で可
5. 「対象」（Audience）→ **「アプリを公開」** →「確認」
   - ⚠️ 「テスト中」のままだと **7日ごとに連携が切れます**。必ず公開してください（「内部」を選んだ場合は不要）
   - 公開しても審査は不要です（使うのはあなただけのため）
6. 「クライアント」→「クライアントを作成」
   - アプリケーションの種類: **ウェブ アプリケーション**
   - 承認済みのリダイレクト URI:「URIを追加」→ `https://（このツールのドメイン）/api/google/callback`
     （正確な URL は、このツールの「面談の日程調整」画面の「Googleカレンダー連携」欄に表示されます）
   - 「作成」→ 表示される **クライアント ID** と **クライアント シークレット** を控える
     （シークレットは**この画面でしか表示されません**。「JSON をダウンロード」で保存しておくと安心。
     見失ったときは、そのクライアントの画面で「シークレットを追加」から作り直せます）

**B. Vercel に登録する**

Vercel の「Settings」→「Environment Variables」で次の2つを追加 →「Deployments」から再デプロイ（Redeploy）。

| 名前 | 値 |
|---|---|
| `GOOGLE_CLIENT_ID` | A-6 のクライアント ID |
| `GOOGLE_CLIENT_SECRET` | A-6 のクライアント シークレット |

**C. Supabase で SQL を実行**

[`supabase/migrations/20261003000000_add_google_calendar.sql`](../supabase/migrations/20261003000000_add_google_calendar.sql)
（追加だけの変更です。未実行でも日程調整・リマインダーはこれまでどおり動きます）

### 連携する

1. 管理画面 →「面談の日程調整」→「Googleカレンダー連携」→「Googleカレンダーと連携する」
2. Google のアカウントを選んで「許可」
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（アプリ名）に移動」（ご自分で作ったアプリなので問題ありません）
   - カレンダーの2つの項目には必ずチェックを入れてください
3. 「空き枠の作り方」を **「Googleカレンダーの空き時間から自動で作る」** にして、受付する曜日・時間帯・面談の長さなどを設定 →「保存」
4. 「面談の空き枠」に「カレンダー」と付いた枠が並べば完了です
5. Meet の URL を送るなら、「確定したときの返信」やリマインダーの文面に `{会議URL}` を入れる
   例: `当日はこちらから入れます：{会議URL}`

| 設定 | 意味 |
|---|---|
| 受付する曜日・受付時間 | この時間の外には枠を作りません（日本時間） |
| 面談の長さ | 予定の長さ。この長さぶん空いている時間だけ枠にする |
| 開始時刻の間隔 | 60分なら 10:00, 11:00…、30分なら 10:00, 10:30… |
| 前後の余白 | 前後の予定との間にあける時間（移動や準備） |
| 何日先まで | 何日先までの枠を作るか |

### うまくいかないとき

- **「連携が切れています。連携し直してください」と出る** →「連携を解除」→ もう一度「連携する」。
  連携が切れている間も日程調整は止まりません（カレンダーの確認と予定の作成だけ行われず、手動の運用と同じになります）
- **7日ほどで毎回切れる** → A-5 の「アプリを公開」がされていません
- **「redirect_uri_mismatch」と出る** → A-6 のリダイレクト URI が画面に表示される URL と完全に同じか確認（`https://`、末尾の `/api/google/callback`）
- **枠が作られない** →「空き枠の作り方」が「自動で作る」になっているか、受付時間が面談の長さより長いか確認。「今すぐ同期」で即時に反映できます

## よくある質問

- **同じ枠を2人が同時に選んだら？** 先着1人だけが確定します。もう1人には「埋まってしまいました」とお詫びして、残りの候補を出し直します。
- **催促は何回？** 1回だけです。番号以外でも何か返事があれば催促しません。
- **手動で日程を決めた人にもリマインダーを送りたい** 「リマインダー」画面の「友だちに登録する」から、予定の日時を入れて登録できます。
- **日程調整をオフにすると？** 今までどおり（自動応答の設定があればそれが返信）です。
- **カレンダー連携で、申込者に Google のメールが届く？** 届きません。予定はあなたのカレンダーにだけ作り、申込者を招待しません。Meet の URL は LINE で送ります。
- **Meet に申込者が入れない？** 招待していない人は「参加をリクエスト」になるので、Meet の画面で「承諾」してください。
- **カレンダーの予定を手で消したら？** 予約は残ります（管理画面の「取り消す」で枠を戻してください）。
