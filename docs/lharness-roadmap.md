# L Harness 機能の取り込みロードマップ

[L Harness](https://github.com/Shudesu/line-harness-oss)（MIT License）にあって、このツールにない機能を順に追加していくための計画です。
用途は **イベント運営** と **個人のコーチング活動** の2つ。役に立つ順に並べています。

## 進め方（安全のためのルール）

L Harness は Cloudflare Workers + D1、このツールは Vercel + Supabase と土台が違うため、コードをそのまま移すのではなく **考え方を参考に作り直す**。

1. **1機能ずつ**追加し、機能ごとにテストと動作確認をしてから反映する
2. DB は**追加だけ**にする（既存のテーブル・列の意味は変えない）
3. 送信が発生する機能は、最初は**オフ**の状態で入れる。テスト送信で確認してからオンにする
4. 既存機能の動きはテストで固定しておき（`npm test`）、壊れていないことを毎回確かめる
5. 追加した機能は、必要に応じて AI 連携（MCP）からも操作できるようにする

凡例: ✅ 完了　🔜 次に着手　⬜ 未着手　🔑 利用者側の準備（外部サービスの登録など）が必要

## 第0段階：土台（先に済ませる）

| | 内容 |
|---|---|
| ✅ | AI連携（MCP）：Claude から話し言葉でステップ配信を作成 |
| ✅ | 認証なしで呼べたAPIの修正（友だち削除・配信状況一覧・ステップ開始/停止・一斉配信） |
| ✅ | 二重送信の防止（予約配信・即時配信・ステップ配信） |
| ✅ | 友だち追加時の自動処理（デフォルトメニュー・自動タグ・追加時シナリオ）の不具合修正 |
| ✅ | 既存の中核ロジックのテスト |
| 🔑 | Supabase で `supabase/migrations/20260930000000_add_message_send_started_at.sql` を実行（未実行でも配信は止まらないが、即時配信の二重送信防止が効かない） |
| 🔑 | DBパスワードの変更（過去のコミットに残っているため） |
| 🔑 | ステップ配信を5分ごとに動かす設定（`docs/mcp-setup.md` の手順4） |

## 第1段階：イベント・コーチングですぐ使う

| | 機能 | 使い道 |
|---|---|---|
| 🔜 | リマインダー配信 | イベント・セッションの日時から「3日前・前日・当日」に自動送信 |
| ⬜🔑 | 個別相談の予約（Googleカレンダー連携・Meet発行） | コーチングの無料相談・セッション予約。前日・1時間前のリマインド付き |
| ⬜ | メッセージテンプレート | よく使う文面を保存して、配信・チャット・ステップで使い回す |
| ⬜ | 未対応の会話一覧 | 返信していない相談を放置時間の長い順に表示（自動応答で済んだものは除外） |
| ⬜ | 友だち追加時設定 | 追加直後のあいさつ・タグ・メニュー・シナリオを1画面で設定 |

## 第2段階：集客と効果測定

| | 機能 | 使い道 |
|---|---|---|
| ⬜ | トラッキングリンク | リンクのクリックを計測し、押した人に自動でタグ付け・シナリオ開始 |
| ⬜ | 流入経路の分析 | QRコード・URLごとに、どこから友だち追加されたかを記録 |
| ⬜ | 配信の効果測定 | 配信ごとの開封・クリックの集計 |
| ⬜🔑 | コンバージョン計測の拡張 | Meta 以外の広告媒体への成果送信（現在は Meta のみ対応） |

## 第3段階：顧客管理（コーチングのクライアント管理）

| | 機能 | 使い道 |
|---|---|---|
| ⬜ | 友だちのカスタム項目 | 目標・受講コース・面談回数などを友だちごとに保存。フォーム回答から自動保存 |
| ⬜ | スコアリング | 反応（クリック・回答・予約）に応じて点数を付け、見込みの高い人を把握 |
| ⬜ | ステップ配信の条件分岐 | 「タグがあれば次へ、なければ別のメッセージ」などの分岐・到達時タグ |
| ⬜ | IF-THEN 自動化 | 「〇〇したら△△する」をルールで設定（タグ付与・シナリオ開始・通知など） |
| ⬜🔑 | 通知ルール | 条件を満たしたら自分に通知（Slack・LINEなど） |
| ⬜ | Webhook 連携（受信・送信） | 外部サービスとのデータ連携 |
| ⬜ | マイル（ポイント） | 参加・回答などでポイントを付与。「マイル」と送ると残高を返信 |

## 第4段階：配信の基盤強化

| | 機能 | 使い道 |
|---|---|---|
| ⬜ | 送信数の監視・警告 | 月の送信枠の使用量を表示し、上限が近づいたら警告 |
| ⬜ | 大量配信のキュー化・再試行キー | 人数が多い配信を分割して確実に送る。再試行しても二重に届かない |
| ⬜ | 送信時刻の分散 | ステップ配信の送信時刻を少しずつずらし、一斉送信の負荷を避ける |
| ⬜ | 緊急停止 | すべての配信をワンボタンで止める |
| ⬜ | ログの保持期間 | 古いログを自動で整理 |

## 取り込まないもの

L Harness を**製品として配布・更新するための仕組み**で、このツールの機能ではないため対象外にしています（必要になれば追加できます）。

- 自動アップデート・アップデートニュース・プラグインマーケット
- セットアップ用 CLI（`create-line-harness`）
- iOS アプリ互換 API・管理者 SSO
- 外部公開用の SDK・OpenAPI（AI からの操作は MCP で対応）
